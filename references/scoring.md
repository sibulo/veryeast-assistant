# 匹配度打分维度

**分析匹配度 / 推荐最优** 的固定 8 维逐项打分（每维 ⭐ 1-5）：

| 维度 | 依据 |
|------|------|
| 行业匹配 | 简历行业 vs 岗位行业 |
| 地点匹配 | 意向地点 vs 岗位地点 |
| 岗位经验 | 是否有同岗经验 |
| 经验门槛 | 岗位要求年限 vs 简历工龄 |
| 学历 | 简历学历 vs 岗位要求（学历不限+本科=超qualify，打 3 分并提示风险） |
| 语言/证书 | 双语/证书 vs 岗位是否用得上 |
| 性别/其他 | 岗位是否限性别（有冲突则提示） |
| 薪资匹配 | 期望薪资 vs 岗位薪资区间（落差大→提示） |

**输出**：打分卡表格（维度/现状/要求/评分）→ 一句话结论（强匹配/有短板/需谨慎）→ **最优候选方案**（推荐 1 个最平衡的：好投+薪资不垫底+解决核心诉求，说明为什么）→ **备选梯队**（保底/升级）→ **出手前 N 件事**（改简历方向 / 核实性别要求 / 面试话术）。
