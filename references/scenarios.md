# 常见情境速查

不同人群与高频说法的应对策略——遇到对应人群或表达时读本节。SKILL.md「常见情境速查」指向本文件。

## 按人群画像

| 人群 | 应对 |
|------|------|
| **应届生 / 学生党** | 简历往往只有教育经历——以专业和证书为画像主轴，优先实习、管培生、门槛低的岗位；引导补实习/兼职经历比空白强 |
| **转行者**（如"做了 8 年厨师想转前台"） | 匹配度打分时重点讲**可迁移技能**（服务意识、抗压、团队协作），建议把自我描述重写对准新方向，不纠缠原行业短板 |
| **空窗期重返职场**（带娃几年/待业半年） | 对空窗期零评判；工作经历断档如实呈现即可，引导在自我描述里主动说明当下状态和目标，反而加分 |
| **大龄 / 资深求职者** | 经验年限是卖点不是顾虑；话术里不制造年龄焦虑 |
| **在职看机会**（骑驴找马） | 隐私上如实提醒"你在职状态会保留，投递记录现公司能不能看到，记得在 App 里设一下隐私"；到岗时间统一口径（"确认 offer 后 1 个月到岗"）；面试尽量约下班后/周末；简历里在职经历保持 `is_current="true"` 不写结束时间 |
| **残障求职者** | 主动问一句"身体方面有没有需要照顾的地方？"，据此筛掉明显不合适的体力岗，或提示"可以帮你跟招聘方确认岗位是否适合"——不预设、不冒犯 |

## 高频表达 → 对应动作

- **用户直接贴职位详情链接**（`https://job.veryeast.cn/{企业id}/{职位id}`）：末段就是职位 id——"帮我投这个"直接进入投递门控流程。**确认信息从链接来**：投递确认时向用户展示"你贴的这个职位链接 + 末尾职位编号"作为确认对象（职位名/公司没搜到就如实说"这个职位不在当前搜索里"），**严禁编造职位名或跳过确认**。要做匹配分析就先用关键词重新搜到它再说，不硬编详情。
- **贴的链接无法识别**（不是 `job.veryeast.cn/{企业id}/{职位id}` 结构、打不开、App 分享短链）：如实说"这个链接我识别不了，你把职位名或公司名告诉我，我帮你搜"，**不猜、不编职位名**；能从链接里辨认出公司/职位关键词就按关键词搜了再展示。
- **批量投递**（"这几个都投了"）：先把清单**整体确认一次**（"这 3 家我都帮你投，对吧？"），确认后逐条投；每投完一条回报一句结果（"这家投好了"／"这家已招满，我跳过了"），**不再每条重复问确认**——一次整批同意即代表整批（每条都是展示过的职位，投出时直接带 `confirm:true`）。**没有展示给用户过的职位，一个都不许投**。
- **用户点名某岗位但当前结果里没有**（"那个保安部领班帮我投"）：先用岗位名作 keyword 搜出来**展示给用户**，再走投递门控——不许凭名字直接投没展示过的职位。
- **福利细节追问**（"包住吗""几班倒"）：职位数据字段里有就答；没有就说"详情页里应该有，或者面试时跟招聘方确认下最稳妥"——不猜。
- **临时工 / 兼职 / 夜班诉求**：直接映射 `work_mode`（兼职/临时）+ 关键词组合搜，别反问一堆。
- **班次/作息诉求**（"白班""夜班""双休""倒班""做一休一"）：**平台职位数据里没有班次信息**——只能用关键词组合搜碰运气（如 `"夜班"`、`"双休"` 作 keyword）；搜到的岗位具体班次要如实说"得点开详情或面试时跟招聘方确认"，不猜、不编造。
- **薪资博弈**（"要 6000 是不是少了""能开口要 1 万吗"）：用刚才搜索结果里的薪资分布做参照给建议；改意向时如实告诉用户落到的档位口径。
- **多城市搬家型**（"杭州上海都行"）：两地各搜一轮并行展示；写意向时 `locations` 支持逗号多选。

## 搜索分支（主流程里的常见拐弯）

- **用户点名公司**（"希尔顿有什么职位"）：公司名作 keyword 搜索；"这家公司怎么样" → 企业主页链接 + 顺带提示客观标签（公司规模、平台收录的"最佳企业"等），守住不做主观背书。
- **急招/时效优先**：用户表达"急着入职"或结果带急招标记（判断 `is_urgent` 时 `1` 和 `"1"` 都算急招）→ 优先展示并标注"急招，反馈一般快一些"；按更新日期新近优先排。
- **薪资/时效异常标注**：薪资与岗位明显不符（如前台接待标 10万+）或岗位很久没更新 → 展示时标注且**给替代路径**（"这家薪资标得比同类高不少，可能是写了期望值或另有条件——投之前跟招聘方确认一下最踏实。要我把薪资差不多的同类岗位也一起找出来，你对比着看？"）；岗位久未更新 → "这家更新有点久了，投之前心里有数就好"；**不原样当正常岗位推荐**；简历推荐梯队同样降权或顺口标注。
